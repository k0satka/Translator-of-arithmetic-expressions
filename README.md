**Лексический анализатор:**
A = { 0-9 + - **  / ( ) .}

| N   | состояние                | символ | действие                             | переход |
| --- | ------------------------ | ------ | ------------------------------------ | ------- |
| 1   | start                    | 0-9    | начать лексему числа                 | 2       |
|     |                          | .      | начать лексему числа                 | 3       |
|     |                          | op     | сохранить оператор                   | 1       |
|     |                          | (      | сохранить лев. скобку                | 1       |
|     |                          | )      | сохр. прав. скобку                   | 1       |
|     |                          | пробел | none                                 | 1       |
| 2   | INT целая часть          | 0-9    | добавить к лексеме символ            | 2       |
|     |                          | .      | добавить к лексеме символ            | 4       |
|     |                          | op     | сохранить число, сохранить оператор  | 1       |
|     |                          | (      | сохранить число, сохр. лев. скобку   | 1       |
|     |                          | )      | сохранить число, сохр. прав. скобку  | 1       |
|     |                          | пробел | сохранить число                      | 1       |
| 3   | DOT точка первая         | 0-9    | добавить к лексеме символ            | 4       |
| 4   | RPART вещественная часть | 0-9    | добавить к лексеме символ            | 4       |
|     |                          | .      | сохр. вещ. число, нач. лекс. числа   | 3       |
|     |                          | op     | сохр. вещ. число, сохр. оператор     | 1       |
|     |                          | (      | сохр. вещ. число, сохр. лев. скобку  | 1       |
|     |                          | )      | сохр. вещ. число, сохр. прав. скобку | 1       |
|     |                          | пробел | сохр. вещ. число                     | 1       |

важно уточнить, что 12..3 распознаеться как 12. и .3 -корректные записи для c++ (некорректна только . но я это учёл), поэтому на этапе лексического анализа ошибки не будет - она возникнет на этапе проверки синтаксиса
